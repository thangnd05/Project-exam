## Chiến thuật cốt lõi

### Quy trình 4 bước (30 giây/câu)

```
Bước 1 (5s)  → Đọc cả câu, xác định loại từ cần điền
Bước 2 (10s) → Loại đáp án sai ngữ pháp
Bước 3 (10s) → Kiểm tra nghĩa + collocation
Bước 4 (5s)  → Chọn đáp án, đi tiếp
```

### Phân bổ thời gian

- Part 5: **≤15 phút** — dành thời gian cho Part 7.
- Tie-breaker: từ loại/thì → collocation → nghĩa ngữ cảnh.

## Bẫy kinh điển Part 5

| Bẫy | Ví dụ |
|-----|-------|
| Sai từ loại | succeed vs **success** sau "a" |
| Sai giới từ | comply **with** |
| Despite/Although | Despite + N / Although + clause |
| Chủ vị | The number **is** / A number of **are** |
| Collocation | **make** a mistake, **take** advantage |
| 2 đáp án đúng ngữ pháp | review vs revise → chọn nghĩa |

## Error log
