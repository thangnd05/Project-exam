## Chiến thuật cốt lõi (riêng Part 3)

### Quy trình (70 giây/đoạn)

```
Trước khi nghe (5s)  → Đọc 3 câu hỏi, gạch chân từ khóa
Trong khi nghe (40s) → Nghe hội thoại, note từ khóa (số, tên, thời gian)
Sau khi nghe (25s)   → Trả lời 3 câu theo thứ tự
```

### Nguyên tắc vàng

| # | Nguyên tắc |
|---|------------|
| 1 | **Đọc câu hỏi trước** — bắt buộc |
| 2 | **Không cố hiểu 100%** — chỉ cần thông tin trả lời 3 câu |
| 3 | **Câu hỏi theo thứ tự audio** |
| 4 | **Paraphrase là chuẩn** |
| 5 | **Đoán nếu bắt buộc** — không bỏ trống |

### Chuyển tiếp Part 2 → Part 3

- Part 2: không có câu hỏi đọc trước → Part 3: **bắt buộc đọc 3 câu**.
- Đổi tư duy: từ 20 giây/câu → quản lý **70 giây/đoạn**.

### Tie-breaker

```
1. Khớp đúng TAG? (detail / next action / imply / who)
2. Thông tin mới nhất? (ưu tiên mới)
3. Ai là chủ thể hành động?
4. Paraphrase có đúng nghĩa?
5. Loại đáp án suy diễn quá
```
