# Part 2 — Question-Response

## Tổng quan

| Hạng mục | Chi tiết |
|----------|----------|
| **Số câu** | 25 câu |
| **Thời gian lý tưởng** | ~8–9 phút (~20 giây/câu) |
| **Định dạng** | Nghe 1 câu hỏi/câu nói → nghe 3 đáp án (A–B–C) |
| **Audio** | Mỗi câu chỉ nghe **1 lần** |

## Chiến thuật cốt lõi

### Quy trình 3 bước (20 giây/câu)

```
Bước 1 (5s)   → Nhận diện LOẠI câu hỏi
Bước 2 (10s)  → Nghe 3 đáp án, loại lạc đề trước
Bước 3 (5s)   → Chọn đáp án hợp lý nhất
```

### Nguyên tắc vàng

| # | Nguyên tắc |
|---|------------|
| 1 | Đáp án phù hợp ≠ hoàn hảo |
| 2 | Loại lạc đề trước |
| 3 | Nắm từ khóa Wh-word là đủ |
| 4 | Cẩn thận đáp án gián tiếp |
| 5 | Từ lặp câu hỏi thường là bẫy (echo) |

### Tie-breaker

```
1. Khớp loại câu hỏi?
2. Có TRẢ LỜI câu hỏi? (không echo)
3. Nghĩa gián tiếp khớp Yes/No ngầm?
4. Phản hồi phù hợp tình huống?
5. Loại câu chỉ lặp từ khóa
```

## Bẫy kinh điển

| Bẫy | Mô tả |
|-----|-------|
| Echo trap | Lặp từ khóa, không trả lời |
| Sai Wh- | Where → trả When |
| Gián tiếp | Không có Yes/No nhưng đúng |
| Đề nghị | Why don't we → không trả Why |
| Tag question | Khớp sự thật |
| How + many/long/often | Bắt trọn cụm How- |
| Near-miss gián tiếp | 2 câu liên quan, 1 trả lời đúng nghĩa |

## Bảng tra nhanh

| Tag | Đáp án mong đợi |
|-----|-----------------|
| Who | Tên / chức danh |
| Where | Địa điểm |
| When | Thời gian |
| Why | Because / lý do |
| How | Cách thức |
| What | Thông tin cụ thể |
| Which | Lựa chọn A hoặc B |
| Yes-No | Yes/No hoặc gián tiếp |

## Error log

**Mẫu:** `Q14 | Where | Echo trap | Fix: hỏi "có trả lời Where không?"`

## Checklist

- [ ] Xác định loại câu hỏi trong 5 giây đầu?
- [ ] Loại lạc đề (sai Wh-)?
- [ ] How many/much/long/often — bắt trọn cụm?
- [ ] Cẩn thận đáp án gián tiếp?
- [ ] Không chọn echo trap?
